CSS 係咩？

一間屋，HTML 係起好嘅牆同柱，CSS 就係油油、揀窗簾、擺梳化——決定間屋靚唔靚、睇落舒唔舒服。

1

一間屋。一個骨架。一個設計師。

HTML 幫你砌好間屋嘅骨架（牆喺邊、門喺邊、標題喺邊）。CSS 就係嗰個室內設計師，話俾啲牆知：「你呢度要白色、呢度要圓角、呢個標題要大大隻藍色字。」

2

CSS 寫法：揀中邊個，再話佢點樣。

CSS 好似一個清單：「標題 → 你要大大隻藍色」、「所有掣 → 你要圓角綠色」、「背景 → 你要淺灰色」。每句都係揀人 → 落指令。

3

CSS 可以改嘅嘢，多到你數唔晒。

顏色、大細、圓角、陰影、動畫、排位（flexbox / grid）——CSS 就係網頁嘅「全套化妝品 + 傢俬 catalogue」。同一間屋（同一個 HTML），換套 CSS 就可以變到完全唔同樣。

✅ 一句總結

HTML 係間屋嘅骨架，CSS 就係油油、揀窗簾、擺傢俬——
決定成間屋睇落靚唔靚、舒唔舒服。

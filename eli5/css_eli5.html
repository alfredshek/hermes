HTML 係骨架,
CSS 係設計師。

CSS(Cascading Style Sheets)就係網頁嘅「裝修師傅」——HTML 砌好間屋嘅骨架,CSS 負責油油、揀窗簾、擺傢俬,令成間屋靚晒。

01一間屋。一個骨架。一個設計師。

HTML 幫你砌好間屋嘅骨架(牆喺邊、門喺邊、標題喺邊)。CSS 就係嗰個室內設計師——話俾啲牆知:「呢度白色、呢度圓角、標題要大大隻」。

02寫法好簡單:揀邊個 → 改咩 → 改成點

CSS 每句都係三部分:揀中邊個元素(h1)→ 改咩屬性(color)→ 改成點(blue)。好似落單咁簡單,唔使記好多嘢。

03CSS 可以改嘅嘢,多到你數唔晒

顏色、字體、大細、圓角、陰影、動畫、排位 —— 同一座 HTML 骨架,換套 CSS 就成間屋變晒樣。呢個就係網頁設計嘅魔法。

一句總結

HTML 係間屋嘅骨架,CSS 就係油油、揀窗簾、擺傢俬——決定成間屋靚唔靚。

1騰訊雲總覽 — 全球佈局同服務家族

騰訊雲(Tencent Cloud)係騰訊旗下嘅公有雲,國內三大雲之一(AWS 全球市佔第一網絡組、Alibaba Cloud 同 Tencent Cloud 並列國產頭兩位)。用開 AWS 嘅人學佢特別輕鬆,因為九成產品都係一一對應:

AWS騰訊雲一句分別
EC2CVM(雲服務器)幾乎同款,連購買流程都似
S3COS(對象存儲)概念 100% 一樣:Bucket + 對象
VPC / SGVPC / 安全組同名同玩法
ELBCLB(負載均衡)應用型/網絡型對應 ALB/NLB
RDSTencentDBMySQL/Redis/TDSQL 系列
EKSTKE(容器服務)都係托管 Kubernetes
LambdaSCF(雲函數)同樣事件驅動計費
IAMCAM(訪問管理)策略語法同 AWS Policy 幾乎一樣
CloudFrontCDN / EdgeOneEdgeOne = CDN+WAF+DDoS 一體化
CloudWatch雲監控指標 + 告警 + 儀表板

1.1 全球地域(Region)佈局

  • 國內:華南廣州、華東上海、華北北京、西南成都/重慶、南京等,每個 region 再有 2–3 個可用區(AZ)
  • 國際:香港(ap-hongkong)、新加坡、東京、首爾、孟買、法蘭克福、莫斯科、聖保羅、矽谷、弗吉尼亞、多倫多等
  • 香港節點:香港用戶做 Website/App 好常用 — 時差近、唔使備案(ICP),出海首選

✅ 記住呢點

備案(ICP)係大陸同香港雲嘅最大分別:國內機房綁定域名一定要 ICP 備案(要幾星期),香港/海外節點唔使。用嚟做玩下/測試,揀香港最爽。
⬆ 回到最頂

2CVM 雲服務器 — EC2 嘅騰訊版

CVM(Cloud Virtual Machine)係騰訊雲嘅核心運算產品,EC2 識嘅嘢全部搬得過去。

2.1 實例家族(對應 AWS Instance Types)

系列型號前綴用途AWS 對照
標準型S5 / S6通用 workloadM5 / M6i
計算型C5 / C6高 CPU 比例C5 / C6i
內存型M5 / M6大內存(數據庫、Cache)R5 / R6i
高 IO 型IT5高隨機 IO(DB)I3 / I4i
GPU 型GN 系列AI 訓練/推理、渲染G4 / P4 系列
裸金屬BM高性能冇虛擬化開銷Bare Metal

2.2 購買模式

  • 包年包月:預付,折扣大(對應 Reserved Instance),長期穩定 workload 用
  • 按量計費:後付,秒級開/關(對應 On-Demand),彈性測試用
  • 競價實例:出價低過基準價就拎到,可隨時被回收(對應 Spot Instance)
  • 共享型實例:同物理機其他人共用 CPU,最平(部分性能唔穩定)

2.3 鏡像同登入

  • 鏡像:公共鏡像(Windows / Ubuntu / CentOS / TencentOS)、自定義鏡像(對應 AMI)、共享鏡像
  • 登入:密碼或 SSH Key;建議 Key,同 AWS 一樣
  • 安全組:實例層防火牆,控制入/出流量 — 同 AWS SG 一樣 stateful

📝 實戰位

① 開機揀好地域+可用區,之後好難搬(要整鏡像先得)。② 數據盤同系統盤分開,系統盤方便重裝。③ 按量實例唔記得關會一路扣錢 — 開「定時回收」或預算告警。
⬆ 回到最頂

3儲存三寶 — CBS / COS / CFS

3.1 CBS 雲硬盤(對應 EBS)

  • 掛喺 CVM 上用嘅塊儲存,同 EBS 一模一樣嘅角色
  • 類型:高性能雲硬盤(HDD)、SSD 雲硬盤、增強型 SSD(對應 gp3/io2)、極速型 SSD
  • 快照(Snapshot):增量備份,可以整新盤 / 跨 AZ 複製 — 對應 EBS Snapshot
  • 可以擴容(要停機或熱擴容睇類型),唔可以縮細

3.2 COS 對象存儲(對應 S3)

概念同 S3 幾乎逐粒字對應:

S3COS
Bucket存儲桶(名稱全球唯一)
Object / Key對象 / 對象鍵
Region所屬地域
S3 Standard / IA / Glacier標準 / 低頻 / 歸檔存儲類型
Lifecycle Rule生命周期規則(轉低頻→歸檔→刪除)
版本控制版本控制(防誤刪)
CORS跨域規則 CORS
S3 + CloudFrontCOS + CDN(靜態網站一體化)

仲有一個 AWS 冇咁平易嘅: CI(數據處理) — COS 直接接圖片壓縮、水印、轉碼,唔使自己開伺服器。

3.3 CFS 文件存儲(對應 EFS)

  • NFS/CIFS 協議共享文件系統,多部 CVM 同時掛載 — 對應 EFS/FSx
  • 場景:共享目錄、WordPress 上傳檔、內容管理系統

✅ 揀儲存快思

系統/數據盤 = CBS;海量檔/靜態資源 = COS;多機共享文件 = CFS;備份 = CBS 快照 + COS 生命周期。審計場景要「不可變」就用 COS 對象鎖(Object Lock,對應 S3 Glacier Vault Lock 思想)。
⬆ 回到最頂

4VPC 私有網絡 — 子網、路由、安全組

騰訊雲 VPC 同 AWS VPC 係同一套思想,而且安全組同網絡 ACL 都係同名同款。

4.1 核心元件

元件用途AWS 對照
VPC私有網段(CIDR),例如 10.0.0.0/16VPC
子網按可用區切網段Subnet
路由表控制流量去邊(IGW/NAT/對等)Route Table
安全組實例級防火牆,stateful(記得返流量)Security Group
網絡 ACL子網級防火牆,statelessNACL
NAT 網關私有子網出去上網,唔俾人入NAT Gateway
對等連接兩個 VPC 相通VPC Peering
雲聯網 CCN多 VPC/IDC 互聯網格Transit Gateway

4.2 出網方式三兄弟(同 AWS 一樣)

  • 公網 IP + 安全組:直接有公網,最簡單
  • NAT 網關:私有實例出街,外面入唔到 — 對應 NAT Gateway
  • CLB + 後端私有實例:流量經負載均衡,後端全私有 — 最 recommended 架構

⚠️ 同 AWS 一個唔同位:公網 IP

AWS 熄機再開(Stop/Start)EC2,公網 IP 會換;騰訊雲按量實例一樣會換,但包年包月實例個公網 IP 通常係固定跟住部機(開「彈性公網 IP EIP」就保證唔會甩)。甩咗要 EIP — 記住呢個詞。
⬆ 回到最頂

5CLB 負載均衡 — ELB 對照

CLB(Cloud Load Balancer)有兩大類,直接對應 AWS ELB 家族:

騰訊雲AWS層級用途
應用型 CLBALB七層 HTTP/HTTPS按 Host/Path 路由、WebSocket、SSL 卸載
網絡型 CLBNLB四層 TCP/UDP高吞吐、長連接、遊戲伺服器

5.1 功能 checklist

  • 健康檢查:HTTP/TCP 探測後端,死機自動踢走 — 同 ALB 一樣
  • 會話保持:七層用 cookie,四層用源 IP — 同 AWS 一樣
  • SSL 卸載:憑證放 CLB,後端行 HTTP — 慳後端 CPU
  • 跨可用區:默認跨 AZ 容災,同 ALB 一樣
  • 訪問日誌:開咗會寫入 CLS(對應 ALB Access Log → S3)
⬆ 回到最頂

6TencentDB 數據庫家族 — RDS 對照

「TencentDB」係一個家族名,下面好多款,認清楚邊個打邊個:

產品係咩AWS 對照
TencentDB for MySQL托管 MySQL:主備、只讀實例、自動備份RDS for MySQL
TencentDB for Redis托管 Redis:集群版、緩存ElastiCache for Redis
TDSQL分佈式數據庫:水平拆分、強一致Aurora / Aurora Serverless
TcaplusDBNoSQL 鍵值,遊戲道具/存檔DynamoDB(遊戲場景專用)
CTSDB時序數據庫(監控指標)Timestream
ES托管 ElasticsearchOpenSearch Service

6.1 MySQL 版核心概念(考你 RDS 知識)

  • 主備架構:一主一備(異地備份加「災備實例」跨地域)
  • 只讀實例:讀多寫少場景橫向擴展,對應 RDS Read Replica
  • 自動備份 + binlog:可以按時間點回滾(Point-in-Time Recovery)
  • 連接方式:內網地址(推薦)或公網地址(要開白名單)
  • 白名單:等於 RDS Security Group,冇加你連唔到 — 三不五時就係呢度卡住人

📝 記住嘅位

① 連唔上 DB = 檢查白名單 + 安全組 + 內外網地址。② 唔好喺公網暴露 DB,要接都經 CLB / 代理 / VPN。③ Redis 用嚟做 cache 就得,唔好當唯一 data store。
⬆ 回到最頂

7TKE 容器服務 — EKS 對照

TKE(Tencent Kubernetes Engine)係托管 Kubernetes,同 EKS 一樣由雲端管 Control Plane,你管 Node。

7.1 同 EKS 嘅對照

EKSTKE
Control Plane 托管Master 托管(可選「獨立集群」自己管 Master)
Node Group節點池(Node Pool,同一個配置一批節點)
HPA / CAHPA + 集群自動擴縮容(CA 對應)
ECR 鏡像倉庫TCR(Tencent Container Registry),支援 Docker Hub 代理
kubectl一樣用 kubectl,憑證由控制台/tkecli 攞
FargateServerless 集群(EKS Serverless) — 唔使 Node

7.2 實戰貼士

  • Pod 要出網:Node 有公網 IP、NAT、或者用 NAT 網關 — 同 EKS 一樣嘅煩惱
  • Persistent Volume:CBS CSI 動態供應(對應 EBS CSI),或 CFS 做 ReadWriteMany
  • 鏡像拉唔到(國內網絡):開 TCR 內網加速,或 Node 設 HTTPS 代理
  • 升級先睇 PDB + 節點排空 — 同 EKS upgrade 嘅規矩一模一樣(唔好跳版本!)
⬆ 回到最頂

8SCF 雲函數 + API 網關 — Lambda 對照

SCF(Serverless Cloud Function)就係騰訊版 Lambda,事件驅動、用幾多計幾多、唔使理伺服器。

8.1 對照表

LambdaSCF
函數 + 觸發器函數 + 觸發器(事件源)
API Gateway 觸發API 網關觸發(RESTful 入口)
S3 事件觸發COS 事件觸發(上傳檔即跑處理)
CloudWatch Events 定時定時觸發(Cron)
記憶體計費(GB-sec)按 GB-s 計費,一樣思想
冷啟動冷啟動一樣存在,熱函數慳時間

8.2 典型用法

  • 圖片上 COS → 觸發 SCF → 自動壓縮/加浮水印 → 寫返 COS(對應 S3 + Lambda 縮圖)
  • 定時任務:報表產生、數據清洗、健康檢查 ping
  • Webhook 接收(IM / 支付回調) + 做後續處理
  • API 網關做認證、限流、版本管理 — 一體化 serverless backend

✅ 一句

「上傳即處理、定時即跑、API 即入口」— 記住呢三句式,就知幾時用 SCF。
⬆ 回到最頂

9輕量應用服務器 Lighthouse — Lightsail 對照

輕量應用服務器(Lighthouse)係騰訊雲嘅「傻瓜 VPS」,同 AWS Lightsail 定位一模一樣:唔使識 VPC/安全組/子網,一拳起個站。

  • 套餐制:CPU/記憶體/流量/帶寬全家桶固定價,冇複雜計費
  • 一鍵應用鏡像:WordPress、Discuz!、LNMP、Docker、遊戲伺服器一鍵起
  • 內置防火牆規則簡單(開放 Port 就係咁簡單)
  • 香港區熱門:唔使備案、低延遲,個人網站/玩下項目首選
  • 對象存儲、CDN、負載均衡都有對應「輕量」版

📝 何時用

寫 Blog / 個人項目 / 試嘢 → Lighthouse;正式生產架構、要 VPC 控制 → CVM + CLB + TencentDB。呢個分界同 Lightsail vs EC2 完全一樣。
⬆ 回到最頂

10CDN + EdgeOne — CloudFront 對照

10.1 CDN(內容分發網絡)

傳統 CDN:源站(CVM/COS)駁 CDN,全網節點快取,用戶就近攞。核心操作:

  • 緩存刷新 / 預熱:更新咗檔案要刷新節點(對應 CloudFront Invalidation)
  • HTTPS:免費 DV 證書一鍵部署到 CDN
  • 回源:源站地址(COS 域名或 server IP)/ 回源 Host 設定
  • 節點覆蓋:國內 + 海外節點,全球一體化加速

10.2 EdgeOne — 新世代融合版

EdgeOne係騰訊雲「CDN + WAF + DDoS + Bot 防護 + 邊緣計算」一體化產品,對應 AWS 要 CloudFront + Shield + WAF + Lambda@Edge 四件夾埋先做到嘅效果。用「一站接入」:DNS 指過去,安全+加速+代碼全部邊緣處理。

💠 騰訊特色位

EdgeOne 有 邊緣函數(Edge Functions) — 概念 = CloudFront Functions / Lambda@Edge:喺邊緣節點跑輕量代碼(改 header、跳轉、A/B)。識 CloudFront Functions 嘅人即場上手。
⬆ 回到最頂

11CAM 訪問管理 — IAM 對照

CAM(Cloud Access Management)係騰訊雲嘅 IAM,而且策略語法同 AWS IAM Policy 幾乎一樣(JSON,Action/Resource/Effect),學過 IAM 即刻睇得明。

11.1 對照表

AWS IAMCAM
Root User主帳號
IAM User子用戶(可選開控制台登入 + API 密鑰)
User Group用戶組
Managed Policy預設策略(QcloudCVMReadOnlyAccess 等)
Inline Policy自定義策略(JSON)
IAM Role角色(跨帳號 / 服務角色)
STS AssumeRoleSTS 臨時憑證(GetFederationToken 等)
MFA登錄保護(MFA)
Access KeyAPI 密鑰(SecretId / SecretKey)

11.2 同 AWS 策略嘅對照(一眼明)

// AWS
{ "Effect":"Allow", "Action":"s3:GetObject", "Resource":"arn:aws:s3:::bucket/*" }

// CAM(結構一模一樣)
{ "version":"2.0",
  "statement":[ { "effect":"allow",
    "action":["cos:GetObject"],
    "resource":["qcs::cos:ap-guangzhou:uin/10000:examplebucket-1250000000/*"] } ] }

見到 qcs(騰訊雲資源描述)就係對應 AWS 嘅 arn。

⚠️ 安全貼士

① SecretKey 千祈唔好 commit 入 Git / 放前端 — 出咗事去 CAM 密鑰管理即刻禁用+重新生成。② 子用戶開 MFA。③ 用「角色 + 臨時憑證」取代長命密鑰,同 AWS 教學一模一樣。
⬆ 回到最頂

12安全產品線 — WAF / DDoS / SSL / KMS

產品係咩AWS 對照
Web 應用防火牆 WAF防 SQL injection、XSS、CC 攻擊;攔截規則 + 白名單AWS WAF
DDoS 高防(BGP 高防 / 高防 IP)大流量 DDoS 清洗,最高 T 級防護;高防 IP 隨時指過去AWS Shield Advanced
SSL 證書免費 DV(單域名/泛域名)+ 付費 OV/EV;一鍵部署 CDN/CLBACM(免費)
KMS 密鑰管理托管加密密鑰,COS/CBS/DB 加密用AWS KMS
雲防火牆 CFWVPC/邊界統一防火牆策略(集中管控)AWS Network Firewall
等保國內「網絡安全等級保護」合規(無直接對應,本地法規)

✅ 部署次序建議

接入順序: DNS(DNSPod) → EdgeOne/CDN(帶 WAF+DDoS) → CLB → 後端 CVM/Security Group → DB 白名單。每一層都係防線,唔好淨係靠安全組。
⬆ 回到最頂

13監控與審計 — 雲監控 / CLS / 雲審計

產品用途AWS 對照
雲監控CPU/記憶體/帶寬指標 + 告警 + 儀表板 + 自定義指標CloudWatch
CLS 日誌服務集中收日誌,全文檢索、告警、投遞 COSCloudWatch Logs
雲審計(CloudAudit)記錄 API 操作(邊個、幾時、做咗咩)CloudTrail
雲撥測全國/全球節點探測網站可用性 + 效能CloudWatch Synthetics
訪問管理 CAM 操作記錄密鑰/登入異常審計IAM Access Analyzer(粗對)

13.1 實戰做法

  • 開 雲監控告警:CPU > 80% × 5 分鐘、磁碟使用率、帶寬突發 → 微信/郵件/短信通知
  • 開 雲審計:出事可以睇「邊個刪咗個 bucket / 改咗邊部機」
  • CLS 收晒唔同產品日誌(CLB 訪問日誌、SCF 函數日誌),一個入口查
  • 告警閾值唔好太敏感,否則噪音大到無人理(告警疲勞)
⬆ 回到最頂

14計費模式與慳錢策略

14.1 三種核心計費模式

模式點計啱用
包年包月一次過俾,月租制,折扣大(1年/3年/5年)穩定生產環境
按量計費按秒/小時扣,彈性開關測試、彈性擴展
競價實例市場價浮動,平好多,但可回收無狀態批次任務、CI

14.2 慳錢 checklist(同 AWS 慳錢思路一樣)

  • 唔用就關:按量機夜晚/週末關,記得設定時回收
  • 長期用就包年:3 年包一般最抵
  • 流量留意:公網流量(帶寬)按量計費可以好快,睇清楚「按帶寬」定「按流量」
  • COS 用生命周期:舊檔自動轉低頻/歸檔,慳 50–70%
  • 快照唔好囤:舊快照定期刪,淨係留增量鏈
  • 代金券/新人優惠:新用戶有唔少體驗金,測試環境啱用

⚠️ 最常見燒錢位

① 開咗部 GPU 機/大記憶體機唔記得關。② 按流量計費冇設上限,被 DDoS/狂拉流量燒爆。③ 快照同鏡像囤積。④ 以為「按量 = 平」,長開 24/7 嘅機其實包年平 60%+。
